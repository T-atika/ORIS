# Playlist Maker

Веб-приложение на Flask для управления музыкальными плейлистами. Позволяет просматривать список плейлистов, открывать подробную информацию о каждом, создавать новые, редактировать существующие и удалять ненужные.

## Реализованная функциональность

- **Редактирование объектов(часть 1)** — кнопка «Редактировать» на странице подробностей, форма с текущими значениями, серверная валидация, возврат ошибок с сохранением введённых данных, перенаправление после обновления.
- **Удаление объектов(часть 2 п.4)** — безопасное удаление через POST-запрос с подтверждением действия.
- **Стиль(часть 2 п.6 + часть 3)** — минималистичный интерфейс в розовых оттенках, единое оформление всех страниц через наследование шаблонов.

## Технологии

Flask, Jinja2, HTML, CSS. Без базы данных, JavaScript и сторонних CSS-фреймворков.

## Запуск

1. Установить зависимости: pip install flask
2. Запустить приложение: python app.py
3. Открыть в браузере: http://127.0.0.1:5000/
