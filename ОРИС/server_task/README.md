# Многопоточный сервер задач

Клиент-серверное приложение для управления общим списком задач. Сервер обслуживает несколько клиентов одновременно, все они работают с одним и тем же списком.

## Структура проекта

- `server.py` — серверная часть
- `client.py` — клиентская часть
- `protocol.py` — протокол обмена сообщениями

## Запуск

Сначала запускаем сервер:

python server.py

Потом в одном или нескольких терминалах клиентов:

python client.py

## Команды клиента

- /add <текст> — добавить задачу
- /list — показать все задачи
- /done <номер> — отметить задачу выполненной
- /delt <номер> — удалить задачу
- /quit — выйти

## Как работает многопоточность

Главный поток сервера крутится в цикле и принимает новые подключения через server.accept(). Для каждого клиента создаётся отдельный поток, в котором работает функция handle_client. Каждый поток независимо читает команды своего клиента и отвечает ему.

## Где и зачем синхронизация

Общий список задач tasks и мьютекс tasks_lock объявлены как глобальные переменные. Lock используется везде, где мы читаем или меняем tasks: в командах ADDT, LIST, DONE, DELT. Без него два потока могли бы одновременно изменить список, и данные бы потерялись.
