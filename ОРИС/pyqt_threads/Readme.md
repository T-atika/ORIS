# Отчет: Доработка сетевого чата

## Что изменилось
- Добавила поле для имени, защиту от пустых сообщений, отправку по Enter и кнопку очистки чата.
- Разделила обработку входящих сообщений на обычные (`chat`) и системные (`system`).
- Сделала текстовый индикатор статуса подключения (зеленый при коннекте, красный при разрыве).
- Настроила корректную обработку обрыва связи и безопасное закрытие приложения.

## Как обрабатывается потеря соединения
Вся логика в `ReceiveThread`. Если сервер падает, `recv()` либо возвращает `None`, либо кидает сетевую ошибку (например, `ConnectionResetError`). 
Я обернула цикл чтения в `try/except`. При любой проблеме поток не крашится, а эмитит сигнал `disconnected`. 
Главный поток (GUI) ловит этот сигнал, меняет цвет статуса на красный, блокирует поля ввода и пишет причину в чат. Виджеты из фонового потока напрямую не трогаем.

## Как организована остановка SendThread
В `SendThread` добавлен метод `stop()`, который кладет `None` в очередь. В цикле `run()` стоит проверка: если из очереди пришло `None` — выходим из цикла.
При закрытии окна (`closeEvent`) сначала вызываю `send_thread.stop()`, затем принудительно закрываю сокет (чтобы разбудить заблокированный `ReceiveThread`), жду завершения обоих потоков и только потом закрываю окно. Это исключает зависания.
