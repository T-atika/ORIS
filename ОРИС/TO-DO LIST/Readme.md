# Task Manager (PyQt6)

Небольшое desktop-приложение для создания и управления задачами, написанное на Python с использованием библиотеки PyQt6.

##  Основной функционал

1. **Создание задачи**:
   - Ввод названия задачи (`QLineEdit`).
   - Ввод многострочного описания (`QTextEdit`).
   - Выбор одного приоритета: Low, Medium, High (`QRadioButton`).
   - Выбор дополнительных независимых настроек: Important, Send notification (`QCheckBox`).
2. **Валидация**: Проверка на пустое название задачи (нельзя создать задачу без имени).
3. **Очистка формы**: Кнопка `Clear form` сбрасывает все поля ввода к значениям по умолчанию.
4. **Удаление**: Кнопка `Delete last task` удаляет последнюю созданную задачу.
5. **Статус и счетчик**: Отображение текущего статуса приложения и количества созданных задач (`QLabel`).

## Дополнительный функционал

- **Отображение внутри окна**: Результат и список задач выводятся не в консоль, а в специальное поле только для чтения.
- **Счетчик задач**: Динамическое обновление количества созданных задач.
- **Фильтрация по приоритету**: Использование выпадающего списка для фильтрации отображаемых задач по приоритету (All, Low, Medium, High).

## Используемые виджеты

- **QMainWindow, QWidget, QVBoxLayout, QHBoxLayout** — для построения адаптивного каркаса окна.
- **QLineEdit** — для однострочного ввода названия.
- **QTextEdit** — для многострочного описания и отображения списка задач (read-only).
- **QRadioButton** — для взаимоисключающего выбора приоритета.
- **QCheckBox** — для независимых настроек (Important, Send notification).
- **QPushButton** — для действий (Create, Delete, Clear).
- **QComboBox** — для фильтрации списка задач.
- **QLabel** — для подписей, статуса и счетчика.

## Запуск
Если у вас еще не установлена PyQt6, установите её через pip: pip install PyQt6
Перейдите в папку с проектом и запустите: python to-do.py
